# Nilam — SIH demo script (~8 minutes)

Login: `admin@landintel.demo` / `demo123`. Keep the browser at desktop width. If anything was changed earlier, use *Data & methods → Reset demo data* first.

**Opening (30 s).** "India's land data, research and policy sit in separate silos. Nilam connects them: Data → Research → Evidence → Policy → Simulation → Pilot → Evaluation → Knowledge. Everything you see is clearly labelled demo data."

## 1. Government — from problem to pilot (4 min)
1. Sign in → choose **Government & Policy**. Point at the *Demo prototype* strip and the Command Centre pipeline.
2. **Policy Problems → PP-024 (Mutation delay).** Show the 8-stage lifecycle bar, baseline, objectives, interventions.
3. **Evidence tab:** open a linked research project and dataset (shows related-record panels). Back, then use *Evidence Explorer* to add one more item.
4. **⌖ View on map:** GIS opens on the right state and layer. Say what the insight bar says, click a district, show related datasets/research/policies, and the DEMO labels.
5. **Policy Simulator (SIM-024):** choose a preset, move a lever, note the assumptions and limitations, **Save scenario**.
6. **Plan pilot:** create it, open the KPIs, **Record readings** twice, **Conclude** the evaluation.
7. **Publish as case study**, then **Generate evidence brief** (print preview). "The loop closes — the evidence from this pilot becomes reusable knowledge."

## 2. Research — gap to publication (2 min)
1. *Switch portal → Research.* **Research Gap Finder** → pick a gap → **Start project**.
2. Add a dataset from **Dataset Discovery**. Open **GIS Workspace**, correlate two layers, **save to project**.
3. **Publish & Case Studies:** create a publication from the project; show Collaboration (team thread).

## 3. Public — knowledge to participation (1.5 min)
1. *Switch portal → Public.* **Knowledge Home** → **Land Atlas** (simple layers).
2. **Policy Explainers** → open one; **State Insights → Tamil Nadu**.
3. **Public Consultations** → open one → submit a response. "Citizens can trace from knowledge to participation."

## Closing (30 s)
"Three portals, one connected record graph, a GIS that explains rather than just displays, and every action persisted. Next phase: live DILRMP / NAKSHA / Bhu-Aadhaar integrations and real boundaries under proper data-sharing agreements."

## Likely questions
* **Is the map real?** No — a schematic cartogram, labelled DEMO; never an official boundary.
* **Are the numbers real?** Synthetic, except programme facts marked *Official programme · summary (verify)*.
* **How does the simulator work?** Transparent linear lever effects with an exponential ramp; assumptions on screen; for comparing options, not forecasting.
